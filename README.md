## 🛰️ Overview

A high-performance, single-file portfolio engineered from first principles. Built with **vanilla web technologies**, zero external frameworks, zero third-party tracking, and zero external media assets.

The aesthetic blends aerospace telemetry, architectural grid blueprints, and retro CRT scanlines with an authentic 24-frame dot-matrix eagle flapping loop and an offline Web Audio ambient synthesizer.

## 🚀 Local Setup & Preview

Because this portfolio is 100% self-contained in a single file, you can preview it immediately:

### Option 1: Double-Click
Simply open `index.html` in any modern web browser (Chrome, Edge, Firefox, Safari).

### Option 2: Local PowerShell Server
Run the included lightweight server script:
```powershell
powershell -ExecutionPolicy Bypass -File server.ps1
```
Then navigate to **`http://localhost:8080/`** in your browser.
